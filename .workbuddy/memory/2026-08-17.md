# 2026-08-17 — VocabHit v0.7.14 Review 复习界面现代化重设计

## 范围
- 仅表现层 + 交互层；Review 业务逻辑、记忆曲线、数据结构、本地存储未触动
- review-active 模式下：隐藏 TabBar、悬浮查词、页头标题/清空；保留单词/按钮区
- 单词舞台中央悬浮 + 极淡紫色环境氛围光；46px 现代粗体（11 字默认、13-15 lg、16-19 md、20+ sm）
- 三枚软色药丸按钮（认识/模糊/不认识），r 18px，色 13/橙/红透明底+饱和文字，scale 0.95 反馈
- 扬声器 38px 圆形，scale 0.88→1 轻反馈
- 屏幕切换：旧屏淡出 110ms → 新屏淡入 300ms + 14px 上推（prefers-reduced-motion 降级）
- 释义页：词性 chip + 释义文本；左侧 4×30px 短色条作为上轮判断印记
- 拼写页：状态化按钮组 [跳过+确认] / [跳过+重新提交] / [下一个]；补全了原本缺失的「拼写正确后下一步」交互（绑定已有 spellNext 逻辑，无新业务代码）
- 完成/过渡页：取消卡片堆叠，三列纯文字统计带细分隔线，去除 emoji

## 关键修复
- `.app.review-active` 选择器 bug（class 实际在 body）→ 改为 `body.review-active`（TabBar/标题/清空/悬浮查词均隐藏）
- 清理 `.review-stat / .spell-word / rvFadeIn / rvSlideUp / fbPop / fbShake` 残留死代码
- preview-review.html 同步注入 `vc-records`，避免 `syncReviewWithWords` 清掉测试数据

## 验证
- 用 headless Chrome（puppeteer-core）跑 4 组视口：390×844 浅色、360×640 小屏、844×390 横屏、390×844 深色
- 全流程：注入数据 → 词义(5 词判断) → 过渡 → 拼写(5 词错+对) → 完成
- 测试脚本要点：直接 `el.click()` + 显式 450ms 等待越过应用内 300ms 操作冷却（避免 puppeteer actionability 与动画竞态）
